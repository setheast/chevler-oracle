# Oracle hand-over — 28 October 2026

**For:** the Chevler Oracle build. Fold into the quoting-module spec (§2 rulings, §5).
**Covers:** production-knowledge §26 (Seth).

## Rulings

1. **Print plates by press** (Seth, 28 Oct 2026).
   - Reel-Sheet: stereo or cylinder. Narrow Reeler: stereo or cylinder. Wide Reeler: cylinder only.
   - A solid print needs a cylinder (a stereo's joint line shows — Stuart, 27 Oct). It can run on any press that takes a cylinder, not only the Wide Reeler (refines ruling 37).
   - **For Oracle:** the Print Tools register holds plate type per press capability; origination is priced per press × plate × colour, and each job/quote records the plate chosen.
2. **An un-costed option is never compared as free.** A route whose plate has no price is excluded from the route comparison (with the reason) until the price is set. This is doctrine for every assumption-engine comparison.
