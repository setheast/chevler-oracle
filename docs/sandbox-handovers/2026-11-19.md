# Oracle hand-over: 19 Nov 2026

**Status:** all live (pushed to main 19 Nov 2026). Not yet folded into Oracle.

Sources: production-knowledge §46–48; `docs/sources/2026-11-19-registered-print-calvi-report.md` (Stuart's written answers + Hannah's call); `docs/reference/2026-11-19-costing-changes-since-lewys-model.md`; build-plan phase log 18–19 Nov; `.claude/rules/settings.md`.

## Rulings

1. **One set of machine rates for every product family (Seth, 18–19 Nov; merged and live 19 Nov).** Main (sheets, reels, discs, liners) now prices from the same machine rows as Cases (one Settings page, `shared-params-store.ts`).
   - Set-up = make-ready hours × the machine's rate: Reel-Sheet 2 h × £51.78, Sheeter 2 h × £62.33.
   - The Slitter and the reelers are priced on running time.
   - Punching is at the PUNCH rate.

   **Effect on live:**

   | Job | Change |
   |---|---|
   | Printed sheet, 10k | +12% |
   | Plain sheet, 20k | +15% |
   | Plain reel | −13% |
   | Liners | about +5% |

   **For Oracle:** a machine-hour rate and a make-ready time per machine, read by every product family. No per-estimator copies, and no template quirk may override a shared rate. Seth blanked the New Chevler £0.40/kg conversion quirk on 19 Nov, after it under-priced a Reel-Sheet job by about £1.76 per 1,000.

2. **Registered print (Stuart + Hannah, 19 Nov; production-knowledge §48).**
   - Printed in register only on the Reel-Sheet (reel-to-sheet press) or Litho, never reel-to-reel then sheeted: the Sheeter can't cut in register.
   - Sheeted only at the register repeats, 305 / 425 / 489mm.
   - Plates: normally a stereo per colour; a cylinder only for a fine design or a long runner.
   - Colours and ink as Random.
   - No known extra set-up or run time; Elliott to confirm.
   - Registered cases run Reel-Sheet → PUNCH → Calvi (or Éclair / Chevlers / cups); registered wraps run on the Zhens. None of Access's 154 registered products ran on a reel.

   **For Oracle:**
   - The print process (plain / random / solid / registered) constrains the route: registered = Reel-Sheet + register cuts.
   - A registered job is proven only by registered history.
   - Print type is a product attribute; its colour count must be recorded (Access doesn't record it).

3. **The Calvi (Hannah, 19 Nov).**
   - Runs about 20–25 strokes a minute and is "temperamental".
   - Nest 16–18 at 50gsm on a 51 × 38; every nest is weighed.
   - Output is never interleaved: the machine tabs cups in set counts.
   - The **jogger** is a vibrating table that squares the sheet stack before punching, not an interleaver.

   **For Oracle:** the jogger is a real routing step on Access; decide whether it carries time.

4. **Minimum order value (Seth, 19 Nov): "£1k + origination".** The goods ex-VAT at each quoted quantity must reach £1,000. Origination and any delivery line come on top. Advisory only: a check with the quantity, or net margin, that reaches it; never a silent price change.

   **For Oracle:** a minimum-order setting and an advisory at quote time, measured on goods.

5. **Plate wording follows the plate.** The quote names the plate priced ("stereos" / "cylinders").

   **For Oracle:** origination lines carry the plate type from the Print Tools register (ruling 120).

6. **Oracle vision, restated by Seth (19 Nov):** "type in the code, or the size, material, print & qtys and a route starts appearing".
   - From a product code, the spec, the proven route and its prices appear.
   - From a bare spec, the candidate routes appear, ranked proven-first then by price.
   - The sandbox did this for UJ002 once registered print existed. It is the acceptance test for Oracle's quoting entry.
